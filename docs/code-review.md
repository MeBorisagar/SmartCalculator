## Code Review Checklist



-  The code follows Java naming conventions and consistent formatting.
- Classes and methods have clear and single responsibilities.
-  Public classes and methods contain appropriate Javadoc comments.
-  User input and expected errors are handled without crashing the application.
-  There is no duplicate, unnecessary, or unused code.
-  Code formatting and quality checks pass successfully.

---

### Self-Review

During my self-review, I found that several Java files did not follow a
consistent formatting style. I improved the code formatting by applying
Google Java Format across the project and reviewing the changes.
